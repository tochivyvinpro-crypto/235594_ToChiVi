\# Hệ thống quản lý thiết bị phòng học



Sinh viên: Tô Chí Vĩ - MSSV: 235594



\## Mô tả đề tài

Ứng dụng quản lý thiết bị phòng học: xem, tìm kiếm, thêm, cập nhật, xóa thiết bị và theo dõi tình trạng sử dụng.



\## Công nghệ sử dụng

React (Vite), Node.js, Express, MongoDB Atlas, Git/GitHub, Docker, Docker Hub, Render.



\## Cấu trúc dự án

\- backend/: Node.js + Express API

\- frontend/: giao diện React

\- README.md: tài liệu dự án



\## Hướng dẫn cài đặt và chạy

\### Backend

1\. cd backend

2\. npm install

3\. Tạo file .env từ .env.example và điền MONGODB\_URI

4\. npm start (chạy tại http://localhost:5000)



\### Frontend

1\. cd frontend

2\. npm install

3\. npm run dev (chạy tại http://localhost:5173)
